# Stone gates v1 — stage 1

Two closed gate sprites: SO (side 2), SW (side 3). Each transparent RGBA PNG is 468 × 501 pixels, with the same fixed baseline, origin and projection as its matching v7 stone wall. No runtime mirroring or stretching. Stone posts, shadows, and wall edge geometry are reused unchanged. The Asset-Labor offers only these two directions for the new stone gate type; the other ten variants remain intentionally unimplemented. These are visual/editor assets, not passability or opening/closing gameplay.
