# Closed palisade gates — AI-painted v3

Five newly generated raster paintings, inspired by medieval RTS timber gates and matched to the accepted palisade v5 style. SO (2) and SW (3) are separate generated images. NO (0), O (1) and W (4) were extracted from a generated three-sprite sheet. NW (5) points to byte-identical SO artwork (same Git blob), using the original NW placement metadata. Only alpha cleanup, cropping, and affine calibration to existing palisade dimensions and foot lines were applied. No SVG or programmatically drawn gate components. Diagonal PNGs retain 420/423 × 444 canvases and edge-on PNGs 84 × 630. Existing palisades, piers, stone gates, geometry, and vegetation clearance are unchanged. The earlier procedural generator and its build workflow are retired. Visual approval in the actual editor remains separate from technical checks.
