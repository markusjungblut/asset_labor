# Closed timber gates v1

Six self-contained SVG game sprites, built from the existing painted palisade v5 directional WebP textures. Original canvas dimensions and grid anchor metadata are unchanged. The four diagonal facings show closed double leaves with timber braces, iron straps and a central seam. The two edge-on facings show only a wider upper timber gatehouse, with unchanged ends. Individual directional wood texture preserves the existing right-side illumination. All use timber join art and the shared global shadow mask. No existing wall, stone gate, or palisade bitmap is modified. The editor supports replacing any legal edge with a palisade gate, persistent facing, and the shared vegetation clearance. Gameplay open/closed state is outside this graphics prototype.
