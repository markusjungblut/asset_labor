# Closed palisade gates — complete AI raster set, NE refinement v7

All six directions use independently generated AI raster gate artwork, except direction 5, which reuses the exact direction 2 PNG bytes with its own existing anchor. The accepted original palisade edge WebPs are the reference artwork. No SVG, procedural gate drawing, or compositing of separate timber images is used in these candidates. Historical v4 composition scripts are not a source for the new set.

Original canvas dimensions and render anchors are retained: 420 × 444 px (0), 84 × 630 px (1, 4), 423 × 444 px (2, 3, 5). Technical preparation uses whole-image geometric calibration, alpha cleanup and modest palette matching. Directions 1 and 4 are independent, non-mirrored edge-on renderings with narrow reinforcement. The original walls, stone assets, joints, shadows and vegetation clearance logic remain unchanged.

NE v7 replaces the earlier twelve-tip candidate with a newly generated ten-tip painting, following the original descending hex projection. Both outer foot points match the reference to within one raster pixel in Y; the two horizontal rails follow the descending edge and remain straight. All six candidate sprites have one connected alpha silhouette and no partially transparent interior pixels (two-pixel boundary excluded), and have been checked against light, dark and green backgrounds. Some texture, tip positions and internal baseline steps still differ from the original walls. Exact visual equivalence and complete browser/editor acceptance are not claimed.
