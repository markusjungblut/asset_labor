# Closed timber gates — raster v2

Six transparent native RGBA PNG game sprites, repainted in pixels using the original painted palisade v5 WebP timber grain. No SVG source is used or rasterized. All original directional image sizes and world anchors are preserved. Diagonal closed double leaves use textured bracing, iron hinges and a lintel. Edge-on gates have wider central timber assemblies, no frontal doors, and retain both original ends. Existing join sprites, lighting/shadow logic, wall placement and vegetation clearance are reused unchanged. Generated reproducibly by `scripts/build_palisade_gate_raster_v1.py`.
