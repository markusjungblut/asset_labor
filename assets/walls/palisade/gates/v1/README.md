# Closed palisade gates — AI-painted v4

Original v5 palisade raster sprites are the base. Only the gate centers use AI-painted image parts, calibrated to the original timber palette and projected slope. The original outer stakes, image dimensions and anchors remain unchanged. The diagonal alpha silhouette is identical to its original source (NW is the requested SO reuse). East/west have a widened central assembly with unchanged ends. All six active assets are transparent PNGs; no SVG or drawn vector door elements. NW (5) reuses SO (2) byte-for-byte. The reproducible compositing script is scripts/compose_palisade_ai_v4.py, with source_atlas_v4.png. The corrected affine composition keeps the timber braces straight. Existing walls, posts, stone gates and vegetation logic remain unchanged. Visual approval in the actual editor is pending.
