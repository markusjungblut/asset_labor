Vedras Reiche – Originalkarten-Renderer testen

Dieser Runner verwendet den vorhandenen Frozen-Viewer in einem eingebetteten Frame. Keine Terrain-Bakes, keine Löschung von IndexedDB oder lokalen Karten. Daten bleiben im Browser, bis du sie ausdrücklich als JSON exportierst.

Gesamttest: Automatisch drei Routen (warme Fahrt, mehrfache 1×/2×-Zoomwechsel, neue Regionen mit Rückfahrt). Auf dem Kandidaten zusätzlich alle vier Optimierungen jeweils A/B/B/A. Ein Klick pro Serverversion, inklusive eines lokalen Gesamt-JSON-Exports. Der Browser-Tab muss währenddessen im Vordergrund bleiben.

Baseline zuerst auf dem main-Server; dann Server stoppen, Kandidaten-Server starten und den gleichen Test mit A/B/B/A ausführen. Immer dasselbe Firefox-Profil und 127.0.0.1:8780 verwenden. Karte und Sichtrechte vor dem Vergleich kontrollieren.

Bereit. Ein Test führt ausschließlich Lesezugriffe auf die vorberechnete Spielkarte aus. Bereits gespeicherte 1×-/2×-Ableitungen können vom Viewer bei Bedarf ergänzt werden.
